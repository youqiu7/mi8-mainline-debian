# 安装指南 · 米8系列 Debian（06-安装包）

> 版本 **20261021-r1**（单版本制：本目录永远只有最新版；迭代时先删旧文件再放新文件，`VERSION.txt` 保留文字迭代史）。
> 基线：Debian 13 + 主线内核 6.19.14 #48 + UEFI(edk2-msm) 引导 + WiFi 修复链（rmtfs 三补丁/EFS 机制/pd-mapper 全家）。

## 1. 适用范围

| 型号 | 状态 |
|---|---|
| **equuleus（小米8 屏下指纹版，225bd9ea 同款）** | ✅ 本包即从该机型实机打包，直接可用 |
| 其他米8系列（dipper / polaris 等） | ⚠ **未验证**。boot 分区（UEFI 外壳）含 polaris dtb，面板/触摸/天线参数以实机取证为准，装完按 §6 判读表逐项核对 |

## 2. 前置条件（新设备）

1. **Bootloader 已解锁**（Magisk 同款流程；不解锁无法刷 boot/写分区）。
2. **adb 可用且有 root**：设备装好 Magisk，`adb shell su -c id` 返回 uid=0。本安装器全部经 adb+su 写盘。
3. Windows 上有 platform-tools（含 adb.exe/fastboot.exe）与本安装包**整个目录**（勿单拷脚本）。
4. USB 连接，装好驱动（CDC/ADB 驱动）。
5. 已读本包 `VERSION.txt`。

## 3. 文件清单

| 文件 | 大小 | 用途 |
|---|---|---|
| `install.sh` | — | 一键安装器（bash，Git-Bash/MSYS 可跑） |
| `rootfs-20261021.img` | 4 GiB（数据~800M） | Debian 根文件系统镜像（ext4，首启自动 resize 到分区全尺寸） |
| `BOOTAA64-20261021.efi` | 43.6 MB | 内核 EFI（ESP 内加载，含 initramfs/固件） |
| `boot-equuleus.img` | 6.66 MB | UEFI 外壳（edk2-msm FD，写 boot 分区）md5 `c7a9acfcda7d405fd7ca2ef2ee72d5e8` |
| `vbmeta-zero.img` | 128 KB | 全 0 vbmeta 备用（米8 出厂即全 0，正常不需要；新机若 AVB 拦截才用） |
| `md5sums.txt` | — | 上述全部文件校验 |
| `安装指南.md` | — | 本文 |

镜像**不含**：EFS 数据（IMEI/校准属每台设备自己，安装器阶段2.5 自动从新机提取）、Android userdata 数据（安装会覆盖 sda23，**先确认可清**）。

## 4. 一键安装

```bash
cd F:/小米刷机/米8移植debian/06-安装包
# md5 自检
md5sum -c md5sums.txt
# 全新设备（含刷 UEFI 外壳）：
bash install.sh --serial <你的sn> --boot
# 已装过本包的设备只迭代系统（不动 boot 分区）：
bash install.sh --serial <你的sn>
```

安装器自动执行：`刷UEFI → 回Android → 提取本机EFS → 写ESP(md5双校验) → 写rootfs(前64MB校验) → 引导 → EFS入位rmtfs → 终验`。日志落 `install-*.log`。

**选项**：`--tools <platform-tools目录>`（默认 dagu 路径）`--key <ssh私钥>` `--com <串口>` `--skip-efs` `--no-boot` `--efi/--rootfs`（显式指定文件）。

## 5. 手动分步（脚本失败时的等价命令）

```bash
ADB=".../adb.exe"; SER=<sn>
# ① UEFI 外壳（fastboot 方式）
fastboot -s $SER flash boot boot-equuleus.img
# 或 Android 方式
$ADB -s $SER push boot-equuleus.img /data/local/tmp/b.img
$ADB -s $SER shell "su -c 'dd if=/data/local/tmp/b.img of=/dev/block/by-name/boot bs=4M && sync'"
# ② 写 ESP
$ADB -s $SER push BOOTAA64-20261021.efi /data/local/tmp/p.efi
$ADB -s $SER shell "su -c 'mount -t vfat /dev/block/sda22 /data/local/tmp/esp; mkdir -p /data/local/tmp/esp/EFI/Boot; cp /data/local/tmp/p.efi /data/local/tmp/esp/EFI/Boot/BOOTAA64.EFI; sync; umount /data/local/tmp/esp'"
# ③ 写 rootfs（会覆盖 sda23 全部数据）
$ADB -s $SER push rootfs-20261021.img /data/local/tmp/rf.img
$ADB -s $SER shell "su -c 'dd if=/data/local/tmp/rf.img of=/dev/block/sda23 bs=4M conv=notrunc,fsync'"
# ④ EFS（本机自己的 IMEI 数据；两分区各 ~2MB，QCOM 标准名）
$ADB -s $SER shell "su -c 'dd if=/dev/block/by-name/modemst1 of=/data/local/tmp/m1.img'"
$ADB -s $SER pull /data/local/tmp/m1.img    # modemst2 同理
# ⑤ 引导
$ADB -s $SER reboot recovery    # → UEFI → Debian
# ⑥ EFS 入位（Debian 起来后）
scp -i <key> m1.img root@169.254.1.1:/var/lib/rmtfs/modem_fs1   # m2 → modem_fs2
ssh -i <key> root@169.254.1.1 "truncate -s 64M /var/lib/rmtfs/modem_fsc; truncate -s 64M /var/lib/rmtfs/modem_fsg; systemctl restart rmtfs"
```

## 6. 首启判读表

| 检查 | 命令/现象 | 预期 |
|---|---|---|
| 屏幕 | 肉眼 | UEFI logo→企鹅（Linux 控制台）；**屏幕/触摸为显示线专项，可能仍黑屏但系统正常**（见 23号） |
| 扩容 | `df -h /` | first-boot 自动 `resize2fs` → **59G**（4G 镜像装机后自动长满分区） |
| 首启标记 | `ls /var/lib/first-boot-done` | 出现=首启流程跑完（时钟/扩容/串口/ssh） |
| SSH | `ssh -i <key> root@169.254.1.1` | 可登（密钥已烧入镜像） |
| 串口 | USB gadget ttyGS0 | root 自动登录 shell（COM 口号随机器变，`--com` 指定） |
| WiFi服务链 | `systemctl is-active rmtfs pd-mapper tqftpserv` | 三 active |
| modem | `systemctl is-enabled mss-start` | **disabled（预期内）**——modem/WiFi 见 25号路线A，勿提前 enable（会 40s 自杀循环） |
| wlan0 | `ip link` | **暂无（预期内）**——待路线A（内核 `QCOM_RMTFS_MEM=y` 重编）完成后出现 |

## 7. 回滚与救援

- **本包写坏 / 想重来**：设备进 fastboot，重跑 §4（安装器幂等，可反复执行）。
- **已装设备系统损坏**：重跑 §4（只更新 ESP/rootfs，保留 boot 分区）。
- **回到原厂**：fastboot 刷原厂 boot/镜像（不在本包职责；原厂分区备份在 `03-备份/`，全0 的 vbmeta 原厂即是，无需处理 AVB）。
- **平台注意**：本机型 `fastboot boot`（临时引导）被平台拒绝、`fastboot reboot` 可能被本工具链拦截——重启用长按电源 10s。

## 8. 迭代规则（单版本制）

1. 新一轮成果验证通过后：**删除**本目录内旧的 `rootfs-*.img` / `BOOTAA64-*.efi`（及旧 `boot-equuleus.img` 若 UEFI 有变），放入新文件并更新 `md5sums.txt`。
2. 在 `VERSION.txt` 追加一行迭代记录（文字保留历史，**文件不留历史版本**）。
3. 打包源流程：活系统上 `tar czf`（排除 `/proc /sys /dev /run /tmp /mnt /var/log/* /var/lib/rmtfs/* /var/lib/first-boot-done`）→ WSL `truncate 4G + mkfs.ext4 -d <解包目录>` → 挂载回读抽查 → 落位改名。
