## 1. 改判 A1（最严重）：`fdtoverlay=` cmdline 机制不存在

- **原结论**（34号§3.3 / HANDOFF§3.3）："新路线已打通：CONFIG_CMDLINE 加 fdtoverlay=xx.dtbo + dtbo 放 ESP（EFI stub OF_OVERLAY=y 支持）"。
- **证伪**（6.19.14 全树 grep）：`fdtoverlay` 仅出现在 `drivers/of/unittest-data/Makefile`（dtc 用户态工具的构建注释）；EFI stub（stub/、libstub/）、drivers/of/*.c、Documentation **零命中**——主线内核无此 cmdline 参数。v15a 测的是不存在的机制，**废弃**。
- **旁证**：`OF_CONFIGFS` 在 6.19 已删（25号§3 副会话早已实测），运行时 overlay 也无门。
- **改判后路线（已拍板 2026-10-23 07:40）：`dtb=` 完整替换**：
  - 证据：`libstub/efistub.h:1132` `handle_cmdline_files(image, L"dtb="…)` + `libstub/fdt.c:251`——mainline stub 真实支持从 ESP 加载完整 DTB 替换 UEFI FdtBlob。
  - 姿势：dump 实机 `/sys/firmware/fdt`（含 UEFI 注入的 memory size）→ dtc 反编译 → **只加不改**（删 chosen 里每次启动变化的 linux,uefi-mmap-*/linux,initrd-* 注入项；memory 节点保留 dump 实测 size）→ 重编 dtb → cmdline（内嵌+FORCE）加 `dtb=equuleus.dtb` → dtb 放 ESP。
  - cmdline 定死后的迭代：**三轮（蓝牙/相机/音频/触摸）的 DT 改动只需替换 ESP 上的 dtb 文件，不再重编内核**。
  - 弃选：of-overlay 自制模块（of_overlay_fdt_apply 虽 GPL 导出于 overlay.c:1075，但无社区先例、晚注入对 serdev/i2c 总线类设备行为未知）；FV 内嵌 blob 替换（改 UEFI 本体，风险最高）。

### 1.1 dtb= 打通过程的四大坑（v16→v19c，2026-10-23 实战，**后续轮次必读**）

1. **SecureBoot 门槛**：fdt.c 忽略 dtb= 除非 `CONFIG_EFI_ARMSTUB_DTB_LOADER=y` **且** `efi_get_secureboot()==disabled`——edk2-msm **没有 SecureBoot 变量**（efivars 实测无）→ stub 保守当 enabled → 忽略 dtb=。**已 patch 去掉该检查**（v17，fdt.c 有 mi8-mainline 注释标记）。
2. **判据错误教训**：`linux,uefi-mmap-*` 属性是 **stub 的 update_fdt 自己写的**（placeholder+exit_boot 时 inplace 更新），不是 edk2 注入——**"chosen 有 mmap-* = 用内置 blob"的判定是错的**（35号初版/36号 v16-v18 三轮被此误导）。真正的判据=自证属性或 dtb 内独有标记节点。
3. **fdt_pack 时机**：往 stub 传给内核的 FDT 加属性必须在 `update_fdt` 内部 `fdt_pack()` **之前**——pack 后 libfdt 视角 totalsize=最小值，setprop 静默失败（v18 的教训，返回值必须检查）。
4. **EFI stub 绝对符号禁令**：stub 代码不许绝对重定位——`static const char *p = "str";` 这类静态初始化指针会生成 R_AARCH64_ABS64 → STUBCPY 拒绝（"absolute symbol references not allowed in the EFI stub"）。用整数 id+局部字符串转换（v19c 方案）。
5. 附：make 管道会吞退出码（`make | tail` 失败仍继续）——构建脚本必须 `make > log; RC=$?` 显式检查；`handle_cmdline_files` 按 **kernel image 同目录+同卷**找文件（ESP 根和 /EFI/Boot/ 都放最稳）。

**当前工作基线（v19c）**：ESP 上 BOOTAA64.EFI=v19c（含自证属性）+ equuleus.dtb=marker 版（c61aa05f，根下 `mi8-dtb-marker{marker="dtb-equals-applied-v19"; test-num=<0x11223344>}`）——marker 每次开机可 `cat /proc/device-tree/mi8-dtb-marker/marker` 自证 dtb= 链路健康。后续轮次改 DT：编辑 `/root/v16/equuleus-marker.dts` → dtc 重编 → scp 覆盖 ESP 两处 dtb → reboot（**零内核重编**）。基线 dtb（无 marker）在 qdebs/equuleus.dtb（5e8873b8）。
