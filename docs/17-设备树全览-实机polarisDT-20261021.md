# 设备树全览：实机 polaris DT vs equuleus.dts（2026-10-21）

> 起因：WiFi 攻坚中拉取实机 `/sys/firmware/fdt`（103,588 B）反编译，确认**本次引导加载的是 polaris（小米 MIX 2S）DT，而非我们编译的 equuleus DT**。应要求暂停刷机动作，完整过一遍设备树，修正此前认知。

---

## 1. 核心结论（认知修正）

1. **UEFI（edk2-msm）内置 polaris DT，EFI 尾部拼接的 equuleus-wifi.dtb 从未生效。**
   - 实机 fdt：`model = "Xiaomi Mi MIX 2S"`，`compatible = "xiaomi,polaris","qcom,sdm845"`，103,588 B。
   - 我们编译的 `equuleus-wifi.dtb`：138,711 B（md5 ae2232a4）；ESP 内另有旧 `equuleus.dtb` 138,570 B（01:05 时间戳，GRUB 路径用）。三者均≠实机 DT。
   - chosen 节点含 `linux,uefi-mmap-*` 注入 → dtb 由 UEFI 装载并处理后交给内核。
2. **实机 polaris DT 对 WiFi/Modem 的配置已完全满足需求**：mss_pil status=okay + polaris 固件路径；wifi@18800000 status=okay + 5 路 vdd + `qcom,snoc-host-cap-skip-quirk`。**不需要再"让 UEFI 用我们的 dtb"**。
3. **equuleus.dts 的全部修改（mss firmware-name / wifi quirk / calibration-variant）在本次引导中未生效**，仅作备用资产保留。
4. 当前 WiFi 唯一卡点 = **WCN3990 供电循环依赖**（见 §4）。

## 2. 实机 polaris DT 关键节点

### 2.1 根节点
| 属性 | 值 |
|---|---|
| model | Xiaomi Mi MIX 2S |
| compatible | xiaomi,polaris / qcom,sdm845 |
| qcom,board-id | <0x2a 0x0>（42） |
| qcom,msm-id | <0x141 0x20001>（SDM845） |
| chosen | linux,uefi-mmap-*（UEFI 注入） |
| memory@80000000 | reg=<0 0x80000000 0 0>（UEFI 填 size） |

### 2.2 reserved-memory（WiFi/Modem 相关）
| 区域 | 地址 | 大小 | phandle | 用途 |
|---|---|---|---|---|
| smem | 86000000 | 2 MiB | 0x02 | SMEM（glink/QRTR 共享内存） |
| tz | 86200000 | 45 MiB | — | TrustZone |
| mpss_region | 8e400000 | 120 MiB | 0x8e | modem 固件加载区 |
| mba_region | 96900000 | 2 MiB | 0x8d | mba 加载区 |
| wlan_msa | 8e300000 | 1 MiB | 0xec | WCN3990 MSA（= 1M，驱动默认 0x100000 匹配） |
| rmtfs | f6301000 | 2 MiB | — | 远程 FS（modem 运行需要） |

> 与 equuleus.dts 的 mpss/mba 布局**完全一致**（8e400000/96900000），互相印证。

### 2.3 remoteproc@4080000（mss_pil）
- compatible = `qcom,sdm845-mss-pil`；reg qdsp6@4080000 + rmb@4180000
- clocks：iface/bus/mem/gpll0_mss/snoc_axi/mnoc_axi/prng/xo（rpmhcc）
- `qcom,qmp`（AOP）、`qcom,smem-states`（stop）、halt-regs 0x23000/0x25000/0x24000
- resets：`mss_restart`（tcsr） + `pdc_reset`（PDC，**需要 CONFIG_RESET_QCOM_PDC=y，已启用**）
- power-domains：cx / mx / mss（rpmhpd）
- **status = "okay"**
- **firmware-name = "qcom/sdm845/polaris/mba.mbn","qcom/sdm845/polaris/modem.mbn"**
- mba/mpss 子节点 memory-region = 0x8d / 0x8e
- glink-edge：label=modem、remote-pid=1、mboxes=APCS、IRQ SPI 449

### 2.4 wifi@18800000（WCN3990）
- compatible = `qcom,wcn3990-wifi`；**status = "okay"**
- reg membase 18800000（8 MiB）；memory-region = wlan_msa（1 MiB）
- clock：cxo_ref_clk_pin（rpmhcc RF_CLK2）；12 个 SPI IRQ（414–425）
- iommus：apps_smmu 0x40
- **vdd-0.8-cx-mx = ldo5（未 always-on）**
- **vdd-1.8-xo = ldo7（未 always-on）**
- **vdd-1.3-rfa = ldo17（always-on，实测 enabled）**
- **vdd-3.3-ch0 = ldo23（未 always-on）**
- **vdd-3.3-ch1 = ldo25（实测 enabled，非 always-on 但被其他消费者开）**
- **`qcom,snoc-host-cap-skip-quirk;` 已具备**

> sdm845.dtsi 的 wifi 节点（5509 行起）：status=disabled、无 vdd、无 quirk → **5 路 vdd 与 quirk 只可能来自板级覆盖**。主线 6.19.14 的 sdm845-xiaomi-polaris.dts 并无 wifi 覆盖 → **实机 DT 来自含 skip-quirk 更新的内核树（edk2-msm 内置）**。

### 2.5 其他
- 屏幕：`/sys/class/graphics/fb0` + fbcon 存在 → 走 framebuffer（UEFI 遗留/efifb），当前显示正常。
- gpu/display/audio/touch 均为完整主线节点（与 equuleus P1 精简版不同，但实机用的是 polaris 完整版）。

## 3. equuleus.dts（我们的板级）vs 实机 polaris DT

| 项目 | equuleus.dts | 实机 polaris DT | 影响 |
|---|---|---|---|
| model/compatible | Mi 8 UD / xiaomi,equuleus | Mi MIX 2S / xiaomi,polaris | 未生效（UEFI 用内置） |
| mpss/mba 布局 | 8e400000(120M) / 96900000(2M) | 相同 | 一致 ✓ |
| mss_pil firmware-name | mba.mbn / modem.mbn（根目录） | qcom/sdm845/polaris/* | **已按 polaris 路径部署原厂固件，modem 启动成功** |
| wifi vdd | 5 路（同） | 5 路（ldo5/7/17/23/25） | 相同；均未在 probe 使能 |
| skip-quirk | 有（我们加的） | **有（UEFI DT 自带）** | 已满足 ✓ |
| calibration-variant | xiaomi_beryllium（我们加的） | 无 | 影响 board-2.bin 选择，暂不影响出网卡 |
| dispcc/gpu/mdss | disabled（P1 精简） | 完整 | 实机走 polaris 完整版 |

## 4. 当前 WiFi 卡点与已实施方案

- **卡点**：WCN3990 供电循环依赖——ath10k 只在 `hw_power_on`（core_start，即 core_register 之后）才 `regulator_bulk_enable`（snoc.c:1026），而 core_register 依赖 wlanfw QMI 服务（FW_READY），wlanfw 需要 WCN3990 上电 → 死锁。实机 ldo5/ldo7/ldo23 实测 un-enabled（ldo17/25 enabled）。
- **已实施（未部署）**：`snoc.c` probe 在 `regulator_bulk_get` 后立即 `regulator_bulk_enable`（patch_snoc_enable.py，脚本已落地 /root）；内核已重编、EFI 已拼装：**BOOTAA64-wifi4.efi md5 497ef15d…（待写入 ESP 验证）**。
- 原厂 modem 分区 FAT（bk_modem.img）已挂载，取得**原厂 mba.mbn（238,304 B）、modem.mdt+b00~b28、wlanmdsp.mbn（3,645,892 B）**；已部署到 `/lib/firmware/qcom/sdm845/polaris/` 与 `ath10k/WCN3990/hw1.0/`，并成功启动 modem（remoteproc0 = running，MBA booted without debug policy → mpss → remote processor up）。
