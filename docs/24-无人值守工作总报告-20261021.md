## 4. 手工模块构建踩坑手册（6.19.14 实录，供未来复用）

1. `make M= 单模块` 的 modpost 在缺 Module.symvers 时报 missing MODULE_LICENSE——因为 **6.19 给 .modinfo 条目加了 `objname.` 前缀**，需 strip（脚本 `scratch/qdebs/strip_modinfo.py`）
2. modfinal 的 `%.ko` 规则依赖 **`scripts/module.lds`**（须先用 cpp 从 module.lds.S 生成，带 -nostdinc + 内核 include 路径）
3. **obj-m 编译必须带 `-DMODULE`**（KBUILD_EXTRA_CFLAGS 传入），否则 extern 符号 insmod 时 "Unknown symbol"
4. 6.19 的 module_init 生成 `__initcall__kmod_*` 符号（无 init_module alias）——手工 .mod.c 需在 `__this_module` 里**显式写 `.init/.exit`**，且 static 入口函数需 `objcopy --globalize-symbol`
5. vermagic 字符串为 **小写 "preempt"**：`6.19.14 SMP preempt mod_unload aarch64`（手写大写 PREEMPT 会被拒 Invalid module format）
6. 手写 gcc 编 .mod.c 需 `-DKBUILD_MODNAME='"rmtfs_mem"'` + 全套内核 include
7. 全套脚本在 `scratch/qdebs/build_ko*.sh / link_ko*.sh`
