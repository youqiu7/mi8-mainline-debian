## 1. 本轮查实的证据链（全部实机/源码级）

1. **QRTR 主干走 modem**：rpmsg 设备列表只有 `4080000.remoteproc:glink-edge.IPCRTR` 等 4 个（全部属于 modem）。modem offline 时远端 QRTR 全死（qrtr-ns 无任何 NEW_SERVER）。
2. **modem 从未健康运行**：dmesg 只有 "4080000.remoteproc is available"，无 powering up。`mss-start.service` 的 ExecStart 未加引号 → systemd 分词错误 → `Syntax error: Bad for loop variable` → 服务从未生效（上一个 agent 的 bug）。20 号归档"modem running 已排除"是错误结论（只看了 state，没看健康度）。
3. **手动 start modem 后**：MBA 加载成功（固件来自本机原厂分区 bk_modem.img，17 号文档有据，固件匹配无虞）→ mpss 每 **40.0 秒** `fatal error without message` 自杀循环（SSR crash #4→#65+），只 announce ssctl(0x42)/sysmon(0x2b) 两个早期服务，26s 时出现 servreg(0x40) 后 14s 死亡。
4. **Kali #9780 同症同平台**（fajita/SDM845）：根因链 firmware path / modem fw / pd-mapper .jsn / ADSP / 顺序。本轮逐项落实：pd-mapper 装好后仍 40s 死 → **排除 pd-mapper 是死因**；rmtfs 才是 EFS 关键。
5. **rmtfs 机制（源码级）**：`sharedmem.c` fallback 链 `/dev/qcom_rmtfs_mem1 → /dev/uio → /dev/mem`；/dev/mem 路径先 `rmtfs_mem_enumerate()`（**匹配 `strncmp(de->d_name,"rmtfs",5)`**）再 mmap。本机 DT 节点名 `memory@f6301000` 不匹配 → size 保持 0 → `mmap(0, 0)` = EINVAL（实测日志吻合）。
6. **DT 节点存在且内存已保留**：`iomem: f6301000-f6500fff : reserved`（no-map 生效）。
7. **/dev/mem 路径可用**（探针实测，与 rmtfs 同构调用）：`mmap(0xf6301000, 0x200000) → OK, first word=0x00002180`（STRICT_DEVMEM 不拦 no-map 区）。**内核与 dtb 都不用改**。
8. WCN3990 侧无硬件缺口：5 路 LDO 实测全部 enabled 且电压正确（ldo5=0.8V ldo7=1.8V ldo17=1.304V ldo23/25=3.0V）；原厂 icnss 节点证明**无独立使能 GPIO**（排除 19c 假设 B）；时序补丁（cold-boot）已由前人验证过仍无效（本轮不再重复）。

## 4. 本轮沉淀的能力（新工具/知识）

- **boot.img/UEFI FD 完整解包链**（可复用于 dtb 修改）：
  `ANDROID! header(page=2048, v1)` → kernel段[2048..] = **gzip(UEFI FD 33,554,560B) + appended Android dtb(494,189B)** → FD: FV@0x80(ffs2,32MB) → [PAD 4000B, SEC, FFS@0x10f40 GUIDED/LZMA 6.1MB] → 解开 = ext_section(0x17)+FV(FFS3,31.3MB) → **dtb FFS@0x1dcc718 (GUID 25462CDA, RAW 103,382B)**，dtb 是倒数第二文件，尾部 FREE 仅 56B（扩容需扩内层 FV，后面零文件，只改 FvLength+checksum 链）。脚本：`scratch/qdebs/` 内 python 段（会话内已验证）。
- **dtc roundtrip 字节级可复现**（103382B→dts→dtb 完全一致，语义零风险）。
- **pd-mapper 的 .jsn 路径机制**：按 DT firmware-name 目录（本机 qcom/sdm845/polaris/）查找；Debian firmware-qcom-soc 在 **non-free-firmware** 组件（pool/non-free-firmware/f/firmware-nonfree/）。
- **rmtfs 链条**：DT reserved-memory 节点（compatible=qcom,rmtfs-mem，名字随意）+ /dev/mem 对 no-map 区可用（无需内核模块/无需重编内核）。
- 交叉编译 rmtfs：arm64 库从 trixie deb 提取（libqrtr1/libqrtr-dev/libudev1/libudev-dev），`make CC=aarch64-linux-gnu-gcc LDFLAGS='-L/root/a64libs -lqrtr -ludev -lpthread'`，**touch qmi_rmtfs.c 跳过 qmic 规则**。

## 5. 教训（勿再犯）

1. **"remoteproc state=running" ≠ modem 健康**：必须看 server announce 数量（健康 mpss 会 announce 数十服务；只有 ssctl/sysmon = 未启动完）。
2. **服务 ExecStart 多命令必须整体单引号包裹**（`/bin/sh -c '...'`），systemd 会分词解析裸命令（本轮修的 mss-start 即此坑）。
3. **多层转义（ssh→双引号→bash→wsl）必炸**：复杂命令写成 .sh 文件（LF）再执行（17b 再次验证）。CRLF 文件先 `sed -i 's/\r$//'`。
4. 设备端 apt 无外网（DNS 不通）：一律 Windows 下载 deb → scp → dpkg -i。
5. `/dev/mem` 探针勿 mmap 普通 RAM 地址（会挂死进程）；只测 reserved/MMIO 区。
