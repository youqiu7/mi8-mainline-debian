# 32-触摸轮-可行性论证与前期调研-20261022

> 时间：2026-10-22 19:50 · 主会话（用户外出期间的前期工作批次）
> 本机硬件：**ST FTS 触摸**（`st,fts`），i2c14（qupv3 0xa98000），地址 **0x49**，第三方换件（29号差异清单）。

## 1. 关键事实

0. **原厂参数已实锤**（micode-dipper-q 仓库的 `equuleus-p0.dtsi` 538-563 行，2026-10-22 夜提取）：
```dts
&qupv3_se14_i2c {
	fts@49 {
		compatible = "st,fts";
		reg = <0x49>;
		interrupt-parent = <&tlmm>;
		interrupts = <31 0x2008>;	/* IRQF_ONESHOT | IRQF_TRIGGER_LOW */
		vdd-supply = <&disp_vddio_vreg>;
		avdd-supply = <&pm8998_l28>;
		fts,irq-gpio = <&tlmm 31 0x2008>;
		fts,reset-gpio = <&tlmm 32 0x00>;
		fts,key-num = <2>;
		fts,key-codes = <158 139>;	/* KEY_BACK / KEY_MENU（虚拟键） */
	};
};
```
→ **INT=tlmm GPIO31、RESET=tlmm GPIO32、i2c=qupv3_se14（0xa98000）@0x49**——触摸轮 fdtoverlay 节点可直接照抄；原厂 st,fts 驱动源码也在仓库（`drivers/input/touchscreen/fts/fts.c` + `fts_521/` 两版）。

1. **主线驱动**：`drivers/input/touchscreen/stmfts.c`——compatible=`st,stmfts`、i2c id=`stmfts`。**与本机 `st,fts` 不同名**。
2. **FdtBlob（真 DT）里大概率无本机触摸节点**：polaris 物料的触摸是 `touchscreen@20 compatible=syna,rmi4-i2c`（Synaptics，地址 0x20）——**与本机 st,fts（0x49）不同芯片不同地址**；Android 时代本机触摸由 vendor 驱动 i2c 手动注册（02号取证）。
3. **社区弹药**：sdm845-mainline 有 `b4/add-support-ft5452-and-ft8719-touchscreen`（Focaltech ft8719=dipper 的触摸）——**不是 ST 系**，但展示了 845 触摸的 DT 接线模式（中断 gpio/pinctrl/regulator）可参考。
4. **22号已批路线**（Q3 P2）：stmfts 改 of_match 支持 st,fts；**本轮补充**：最小改法=of_match 表加 `.compatible="st,fts"` + i2c_device_id 加 `"fts"`（两行）。**前提是协议兼容**——st,fts 与 st,stmfts 同厂（ST）但系列不同（FTS3/5/6 协议有差异），需 chip ID 实测后判断改驱动的深度（寄存器级 or 仅握手）。

## 2. 把握度

| 分项 | 把握度 | 依据 |
|---|---|---|
| i2c 总线/中断通（设备出现在 i2c14） | **85%** | Android 已工作（02号 sysfs 实测），硬件不变；剩=中断 gpio 号未知（原厂驱动/MiCode 或实测） |
| 驱动 match 成功 | **95%** | 加两行 id 即 match（Q3 已批） |
| 触摸事件流（input 上报） | **60%** | 若芯片=FTS5 系（同 stmfts）→ 低改动；若 FTS3/定制协议 → 需 MiCode 原厂 st,fts 驱动源码移植寄存器序列（工作量升至中） |
| 多点/手势完整 | **50%** | 依赖协议族判断 |

## 3. 执行序（联调时）

1. 设备在线时：`i2c detect` 确认 0x49 在线 → `i2cget` 读 chip ID 寄存器（FTS 系列 ID 寄存器 0xA0/0xA3）
2. 型号定性 → 决定：仅加 id（FTS5 近亲）or 移植原厂序列（MiCode 下载 st,fts 源码）
3. 中断 gpio：从 MiCode 原厂驱动 dtsi / 实测 gpio 配置（fdtoverlay 或驱动内 gpio 标号）
4. config：CONFIG_TOUCHSCREEN_STMFTS=y + 上述修改
5. 判据：`/dev/input/eventX` 出现 ST 触摸设备；evtest 有坐标事件
