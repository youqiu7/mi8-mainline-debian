## 5. ABL 引导路径实验（本窗口主体，已关闭）

### 5.1 动机
pmOS 当年在 ABL 下 beryllium WiFi 可亮（遗留供电假说）；UEFI 路径多版本冷启动无效。用户插问 UEFI 是否适配本机电路，并明确指示"尝试使用原厂boot.img的外壳重新打包系统内核"。

### 5.2 已走步骤与结果（全部落档）
1. **fastboot boot 临时引导**：原厂镜像也被拒（`FAILED 00000050`）→ 平台禁 fastboot boot 临时引导。
2. **flash boot 带 EFI stub 内核**（4 版：boot-mainline 至 -mainline4）：全部引导失败回落 fastboot。镜像 md5：
   - boot-mainline=e588f396b0b2e123e2ca0830273bca8c
   - boot-mainline2=d8f5de5727896ee1d674b8aef87053ce
   - boot-mainline3=7fbf67fc0da5cab7eb8c20b6fbac433b
   - boot-mainline4=052a79ee97cb423c3b149c219df704cb
3. **根因定位**：原厂 boot.img kernel 段 gzip 解压后头部 `00007e14...`（ARM64 引导指令，无 MZ）；主线 Image 头部 `4d5a40fa`（MZ，EFI stub PE 头）。推断 ABL 按头部判定 payload：MZ→UEFI 固件路径；无 MZ→Linux 内核路径。
4. **无 stub 内核实验（本轮）**：
   - **编译管线打通**：`CONFIG_EFI_STUB` 被 `arch/arm64/Kconfig:2427` 的 `select EFI_STUB` 强制依赖 `CONFIG_EFI=y`——**要无 stub 必须 `CONFIG_EFI=n` 一起关**（ABL 路径不需要 EFI，UEFI ESP 继续用带 stub 内核，双内核并存）。
   - 产物：Image 头部 `1f 20 03 d5`（nop，ARM64 指令，无 MZ）✓，25,618,440B；gzip 后 12,529,521B。
   - 打包：boot-nostub.img（14,893,056B，ANDROID! v1：page=4096、kernel_addr=0x8000、ramdisk_addr=0x1000000、os_version=0x1400014c、ramdisk=usr/initramfs_data.cpio.gz 2,217,493B、dtb=equuleus-wifi.dtb 138,711B）——头部字段验证通过。
   - **刷入结果：ABL 仍引导失败回落 fastboot。**
5. **结论（ABL 路径关闭）**：ABL 对非原厂 boot 分区兼容性差为**确定事实**，与内核是否带 stub 无关。ABL 遗留电假说无法在本机验证（引导层到不了 WiFi 层）。**boot 分区已恢复 boot-equuleus.img（UEFI 版）**。

## 8. 环境教训与执行规范（重要，勿再犯）

1. **WSL 后台进程不可靠**：`nohup/setsid` 后台编译进程随 wsl 会话结束被回收（Hangup）；PowerShell run_in_background 的 wsl 任务也会被环境清理。**重活必须在单次前台 wsl 调用里跑完**（工具超时上限 300s；编译须拆小步或一次完成），且**用户消息会打断 TaskOutput 等待→杀死 wsl 编译**——编译前告知用户勿打断。
2. **编译命令必须带 `ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu-`**（wsl 新会话环境变量不保留；漏了报 "No rule to make target"）。
3. **EFI_STUB 依赖**：`CONFIG_EFI=y` 强制 `select EFI_STUB`（arch/arm64/Kconfig:2427）——无 stub 必须 `CONFIG_EFI=n`。改 .config 用 `sed -i 's/^CONFIG_EFI=y/# CONFIG_EFI is not set/'`，改后必须 `make olddefconfig` 固化（否则 make 会回滚）。
4. **make 交互卡死**：Kconfig 出现 NEW 选项时用 `make olddefconfig` 自动填充，不要裸跑 make 等待交互。
5. **PowerShell 转义**：wsl 命令的 `$` 转义为 `\$`；awk 单引号内的 `$5` 会被 PowerShell 先行求值（报 "unexpected character"）——**避免在 PowerShell 双引号里用 awk，改用 ls -la 或写文件再读**。
6. **wsl 输出可能被吞**（exit 0 空 stdout）：关键验证结果**写文件（/mnt/c 或 Windows 路径）再 Get-Content 读回**。
7. **pkill 匹配自身**：`pkill -f 'Image.gz'` 会杀掉命令行含该串的当前 bash——用精确模式或 `pgrep -c` 先查。
8. **fastboot reboot 被系统拦截为高危**：设备重启只能用户手动（长按电源 10 秒）；`fastboot boot` 临时引导被平台拒（00000050）——勿再试。
9. **恢复保底**：任何 boot 分区实验前，确认锚点 `boot-equuleus.img` 可用（已实测恢复）。
