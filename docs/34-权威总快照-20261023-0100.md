## 3. 关键技术结论（防重复踩坑）

1. **initramfs**：重编必须用 `/root/initramfs-full`（V1 提取的完整启动盘），`/root/initramfs-fw` 只有固件没有 /init，用它必 panic。EFI 内嵌 initramfs=gzip 段（假魔数多，需解压验证）。
2. **构建**：`CC=clang`（Debian 19.1.7，路径 /usr/lib/llvm-19/bin）+ `CROSS_COMPILE=aarch64-linux-gnu-`。gcc 未验证但不必要。
3. **DT 生效铁律**：appended dtb 无效（EFI stub 用 UEFI FdtBlob）。~~新路线已打通：CONFIG_CMDLINE 加 fdtoverlay=xx.dtbo~~ **【35号改判 07:50】`fdtoverlay=` cmdline 机制在 6.19.14 不存在（源码级证伪），v15a 废弃**。改用 **`dtb=` 完整替换**（libstub/efistub.h:1132 真实支持）：dump 实机 fdt → 反编译只加不改 → cmdline（内嵌+FORCE）加 `dtb=equuleus.dtb` → 后续三轮 DT 迭代只换 ESP 上的 dtb 文件。详见 35号§1。
4. **FdtBlob 子系统节点（35号§2+07:55 复核）**：bluetooth **已就位**（geniqup@8c0000/serial@898000 下 wcn3990-bt 完整节点，父 UART okay——DT 前置=零）；sound **空壳目录**（无 compatible）；camera **camss/cci 属性完整但 status=disabled**（非缺失）；i2c SE **全在 geniqup 子层级**（i2c@a98000 okay，本机 st,fts@49 需注入）；charger 外设缺（28号✓）。详见 35号§2。
5. **恢复通道**：fastboot flash mindowsesp + esp-full-20261022.img + fastboot continue。三次实战验证。
